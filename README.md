# DevOps OS

Sistema Linux construído a partir dos fontes para especialistas em DevSecOps e SRE. O objetivo é ver de perto o que costuma ficar escondido atrás da distribuição pronta: boot, usuários, permissões, pacotes, rede e o que o sistema realmente executa.

Criei o DevOps OS para aprender mais e me especializar em Linux.

## Créditos

- [Linux From Scratch](https://www.linuxfromscratch.org/), que define o caminho de construção do sistema.
- [Caio Henrique](https://github.com/Caiohenrks), autor deste projeto.
